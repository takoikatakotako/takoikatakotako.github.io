概要

GenesisはARKit を活用したラジコンカー操作 iOS アプリです。カメラをかざすだけで目の前の空間にクラシックカーが登場し、画面上のスティックで自由に操作できます。

主な機能

  • ARKit による高精度な拡張現実体験
  • 直感的な操作スティックでかんたん操作
  • かわいいクラシックカーのミニチュアモデル
  • リビング、公園、どこでも走れる

技術スタック

  • Swift / SwiftUI - iOS アプリ開発
  • ARKit - 拡張現実機能
  • RealityKit - 3D モデルレンダリング
