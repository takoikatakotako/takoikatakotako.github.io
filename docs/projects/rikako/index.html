概要

Rikakoは、化学を中心とした問題集アプリです。問題集を選んでクイズ形式で学習し、解説を確認しながら理解を深めることができます。

主な機能

  • 問題集の一覧・詳細表示
  • 4択クイズ形式での学習
  • 解答後の即時フィードバックと解説
  • 成績の確認（正答率・結果一覧）

技術スタック

  • Swift - iOSアプリ開発（SwiftUI）
  • Go - バックエンドAPI（Echo v4）
  • PostgreSQL - データベース（Neon Serverless）
  • AWS - Lambda, S3, CloudFront, Cognito
  • Terraform - インフラ管理
